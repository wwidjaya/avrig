# avrig-ai

avrig-ai is an open-source project to build an autonomous agentic engineering system for system development. It explores how people and AI agents can work together as a virtual company to plan, coordinate, and carry out engineering work.

The project brings together company actors, agent execution, engineering tools, and user-facing interfaces under a shared system. Its goal is to make complex system development more organized, observable, and capable of progressing through coordinated autonomous work.
