# Avatar

This area contains the PET avatar options and the plan for building the avatar system first.

- [20 PET avatar options](AVATAR_OPTIONS.md) lists the proposed visual identities for review.
- [Avatar Development Plan](DEVELOPMENT_PLAN.md) sequences selection, the avatar contract, the first asset set, presentation runtime, and later desktop integration.

The initial development scope is the avatar itself. Office UI, agent behavior, and the 3D office are later integrations. Avatars are visual projections of PET/Employee identity and status; they do not own identity, permissions, or agent execution. No option has been selected as the default yet.
