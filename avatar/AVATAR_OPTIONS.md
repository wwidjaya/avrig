# PET Avatar Options

**Status:** Proposed options for human review. Names and visual directions are working concepts, not finalized character designs.

These 22 options are candidate visual identities for the avrig-ai PET. Each keeps the same character identity across connection states: when not connected, the PET wears a T-shirt and jeans; when connected, it wears the same outfit with an additional jacket. The jacket communicates connection only; it does not imply authority or role.

## Shared design rules

- Keep the face, body, motif, and palette consistent between connection states.
- Use the T-shirt-and-jeans base outfit when not connected; add a jacket when connected.
- Keep the motif subtle so the connection state remains easy to read.
- A tablet prop may be shown while the PET is presenting a message or alert; it does not indicate connection state.
- Provide text and accessible status labels; never communicate important state through artwork or color alone.
- Review representation, readability, and asset provenance before selecting or releasing a design.
- Treat avatar identity as presentation metadata, separate from Actor/Employee identity, permissions, and Agent Runtime.

## Selection status

No option is selected as the default yet. The catalogue is a starting point for visual exploration and user review. Names and visual directions can be revised without changing stable option IDs; retired IDs should not be reused for unrelated identities.
